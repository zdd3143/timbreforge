# 用一句描述，创造角色的声音

## 打开软件

在已配置好的 Windows 本机，双击仓库根目录的 `启动声线工作室.cmd`。保持启动窗口运行，浏览器会打开 `http://127.0.0.1:7860`。关闭启动窗口即可停止服务。

第一次使用可以双击 `安装并启动声线工作室.cmd`。它会自动创建隔离环境并安装界面依赖；模型路径配置和整合包说明见 [Windows 小白整合包](WINDOWS_BUNDLE.md)。

也可以在项目目录运行 `python -m timbreforge.launcher`。如果端口已占用，使用 `python -m timbreforge.launcher --port 7862`。

新机器需要先安装 `python -m pip install ".[ui]"`，将 `timbreforge.example.toml` 复制为 `timbreforge.local.toml`，填写本地 Qwen Python、VoiceDesign 和 Base 模型路径。具体模型准备见 [VOICE_DESIGN.md](VOICE_DESIGN.md)。模型不包含在软件发行包里。

## 设计第一个角色

如果已有角色背景资料，可在第一项「角色设定 → 声线推演」导入 Word `.docx`、TXT、MD、JSON 或粘贴设定，点击推演后查看并修改模型给出的提示词，再生成试听。详见 [角色设定导入指南](ROLE_PLANNER.md)。

首页「简化版 · 一句话生成」只需输入声线描述，点击“生成角色声音”即可试听和下载。不需要填写台词、选择设备或勾选额外确认框。软件读取模型自带采样配置，自动检测 GPU（无可用 CUDA 时使用 CPU），随机选择种子，并使用简短的中文试听台词；短试听的 token 上限为 1024。再次点击可生成另一版，之前结果仍保存在设计会话中。

这里的自动配置是采用模型自带生成设置，声音风格由 VoiceDesign 根据描述生成；并没有额外语言模型猜测一组采样参数。

推演成功后，音频下方会出现「生成记录」。按 **记录一 / 记录二 / 记录三** 点选即可切回之前生成的声音（最多保留 3 条，再生成会删除最早的一条）；「↻ 换个种子重新生成」会用当前文字再生成一版。满意后点「保存这条声线到声线库」，填写角色名（描述选填）并确认已试听。

右上角「声线库」可以查看已保存的角色和它们的全部声线；**同一个角色可以有多条声线**，保存时在「保存到」里选择已有角色即可追加。详见 [角色设定导入指南](ROLE_PLANNER.md)。

需要手动调整或保存角色时，打开「文字声线设计 / Qwen VoiceDesign」。进阶页的生成按钮会在勾选用途确认后启用，避免未确认时点击弹出错误。以下是进阶页操作：

1. 在首页左侧填写声音描述，例如：**成年女性，中低音，清冷沉稳，略带沙哑，吐字清晰，像星际飞船的领航员，自然而克制。**
2. 输入试听台词，例如：**航线已经确认。别担心，我会带你平安回家。**
3. 保持候选数为 1、GPU 设备和默认参数，确认合成声音用途后点击“生成新声线候选”。首次运行需要加载模型。
4. 在右侧播放候选 A。想比较不同声音，可以换一个种子，点击“追加候选”；想换描述或试听台词，点击“生成新声线候选”建立新会话。
5. 直接试听 A 或 B，分别填写角色名称后点击“保存 A 到角色库”或“保存 B 到角色库”。不需要额外收藏、备注或二次确认。
6. 打开“角色复用”页，刷新角色列表，选择角色并输入新台词。此时使用已保存的参考声音进行生成。

播放器可下载 WAV。关闭软件后，设计候选与角色会保留；重新打开时点击“刷新会话列表”并加载会话。模型参数保存在每个候选的记录中。

## 本机文件

按示例配置，输出位于 `.local-data/outputs/`，角色库位于 `.local-data/characters/`。请一起备份角色音频和元数据。软件不会把生成的参考音频当作训练出的新模型。

“本地模型与环境”中的检查按钮会报告缺失的模型文件，也可以运行 `python -m timbreforge.launcher --check`。文件检查不保证 GPU 和 Python 依赖正常；实际运行失败时，错误消息会指向生成日志。

声线描述是生成方向，需要试听挑选。固定参考可用于后续台词，但不保证所有语句的声音身份和表演完全一致。
