# 声线微调、长文本与自动评估

这三项都属于“先试听再决定”的辅助能力：程序负责生成可比较的候选、检查明显异常并保存证据，不替用户判定哪个声音更好。

## 声线微调（候选与 A/B）

工作流：

```text
选择角色 -> 确认 VoiceRecipe -> 输入试听台词 -> 生成 4–8 个单维候选
        -> 逐条试听 / A/B 对比 -> 选中一个 -> 保存为角色新版本 -> 重建 Clone Prompt
```

实现：`timbreforge/voice_candidates.py`，会话保存在 `outputs/tuning/<session-id>/`。

- 每个候选只改变一个表达维度（语速、情绪、能量、停顿、句尾、重音、咬字或句子长度），音色与身份不变。
- 候选记录：提示词、seed、模型目录与配置哈希、`qwen-tts` 版本、角色 ID、角色版本、完整配方、变化维度与音频 SHA-256。
- 候选音频为 FLOAT WAV；`compare()` 生成的可选响度对齐副本只用于播放，原始候选不被修改。
- 保存为新版本前必须由用户选中候选并勾选“确认音频与逐字稿逐字一致”。保存会：

  1. 把候选音频复制为角色目录中的 `audio/promoted-<hash>.wav`；
  2. 写入 `promote_candidate` 历史事件；
  3. 更新逐字稿与配方，递增角色版本；
  4. 使旧 Clone Prompt 失效，并按需重建。

- 如果 Clone Prompt 因模型不可用创建失败，**新版本仍然保存**，界面会提示下次生成回退到普通克隆。

会话可以被丢弃（`discard_session`），只删除候选与记录，不会修改角色卡。

## A/B 对比

`compare()` 使用 `timbreforge/candidates.py` 生成两条播放副本，可选择 RMS 响度对齐。它不改变原始候选、不自动选优，也不把响度匹配当作响度标准化。界面上 A/B 只用于人耳判断。

## 长文本生成

实现：`timbreforge/longform.py`。

```text
长文本 -> 按段落/句子切分（不丢字） -> 同一角色逐段生成 -> 覆盖/重复检查
      -> 突发加速/音量跳变/音色漂移/点击检查 -> 淡化拼接 -> 输出 WAV + JSON
```

- `split_text(text, max_chars=120)` 保留每一个字符；超长句先按逗号、再硬切分。
- `check_segments` 检查漏句、重复、顺序与模型幻觉出的文本。
- `analyze_segments` 为每段计算时长、字/秒、LUFS、峰值、首尾静音、削波数、频谱质心与点击事件，并用中位数识别异常。
- `concatenate` 在段落边界做升余弦淡化并插入可配置间隔；拒绝覆盖、拒绝采样率不一致。
- `generate_longform` 逐段调用统一生成入口，保存每段文本、seed、参数、生成记录路径与检查报告；失败或取消不会发布半成品。

这些检查是辅助警告，不保证语气衔接自然；长文本仍需要完整试听。

## 固定测试集与自动评估

实现：`timbreforge/voice_eval.py`。

固定测试集覆盖八类文本：低情绪短句、疑问句、命令句、长句、数字与专有名词、高情绪句、冷淡低能量句、声母韵母覆盖句。

评估指标：

| 指标 | 说明 |
| --- | --- |
| CER | 用户提供的转写与期望文本的 Unicode 编辑距离（含标点）；不做 ASR |
| WER | 仅空格分词文本；中文标记为不适用，不伪造数字 |
| 说话人相似度 | 可选，调用本机 CAM++ 评分器；不可用时标记 unavailable |
| 时长 / 语速 | 时长与字符/秒，用于发现异常拖长或加速 |
| 首尾静音 | 20 ms 帧、-42 dBFS 阈值 |
| 峰值 / LUFS / 削波 | 响度与削波统计 |
| 音色漂移 | 候选与参考的频谱质心比值（粗略代理，不是身份判定） |
| A/B 评分 | 用户 1–5 分，人工意见 |

`evaluate_candidate` 未提供转写时，准确率保持 `unverified`/`None`，绝不会显示为 0 分或“通过”。`summarize` 同时给出各指标平均值与**最差候选**，避免只看平均效果；未测量指标会单列。

报告以 UTF-8 JSON 原子写入，可附带固定测试集、模型版本、角色 ID 与生成记录。

## 限制

- 所有指标都是辅助证据，不是自动排名、身份认证或 MOS 保证。
- 音色漂移只看亮度；情绪和咬字变化不会被它识别。
- 长文本检查无法发现语义错误或语气不连贯。
- 候选使用 VoiceDesign 生成新参考，因此“试听台词”会成为新的参考逐字稿；必须保证二者逐字一致。
