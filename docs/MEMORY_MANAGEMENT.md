# 克隆与模型内存管理

参考克隆页面默认使用本地 Qwen Base 0.6B。提供 30 秒以内的原始参考音频、准确转录及新台词即可生成；Qwen Base 不消费独立表演指令。IndexTTS 需要已启动且正确配置的 ComfyUI，CosyVoice3 需要其独立模型与运行环境。

## 自动资源释放

- 推演、声线设计、克隆、IndexTTS 及评分模型共用资源锁。同一输出目录中的工作室和命令行进程也会串行执行，避免各自加载模型挤占内存。
- 加载独立模型前，释放本机配置的闲置 ComfyUI 模型、IndexTTS 专用缓存及执行缓存。IndexTTS 合成结束后也请求释放缓存。ComfyUI 有运行或排队任务时会提示等待，不打断任务。
- Qwen、CosyVoice、推演及评分使用一次性子进程；调用方等待子进程退出后才释放资源锁。正常完成、Python 异常和超时退出后，模型由操作系统回收。
- Qwen 检测到显存不足、MemoryError 或 Windows 页面文件不足时，在失败进程退出、清理闲置缓存后使用原参数自动重试一次。其它错误直接显示原因，不反复加载模型。

仅管理本软件发起的模型调用和已配置的本机 ComfyUI 缓存；不会强制结束浏览器、dsh 或其它外部程序。不同输出目录的实例、其它软件直接使用 GPU，以及操作系统提交内存上限仍可能造成资源不足。软件不会自动改系统分页设置或切换到 CPU。

## 降低单次克隆峰值

长台词优先按句子边界拆分，每段最多 100 字符，顺序生成；参考声音条件只构建一次并复用。拼接生成波形时不插入额外静音，不改写台词、不裁切参考。分段可能影响语气衔接，界面会提示试听确认，元数据记录 `text_segments`。

读取参考音频前先检查时长和采样数量，避免把明显过大的文件整体解码进内存。模型以 `low_cpu_mem_usage=True` 加载，参考校验副本在推理前释放。

## 本机验证（2026-10-16）

RTX 4060 Laptop 8 GB、约 16 GB RAM，使用项目自生成的参考声音：长台词分 2 段，得到 25.36 秒 / 24 kHz 音频，PyTorch 峰值分配显存 2,788,283,904 字节（约 2.60 GiB）。整卡占用从运行前 1342 MiB 回到结束后 1340 MiB。记录位于本机忽略目录 `.local-data/memory-acceptance.json`。

这验证了生成与资源释放流程；声音贴合度、逐字转录和段落衔接仍需试听确认。
