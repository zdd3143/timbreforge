# 声音权利、隐私与安全

## 使用前取得许可

参考音频的“可下载”不等于允许克隆、训练、商业使用或再发布。请核实说话者授权、录音版权、数据集条款、用途/期限/撤回机制及所在地区适用法律；涉及未成年人等情形应特别审慎。合成音也可能受到来源模型、数据或人格权限制。

CLI 的 `--confirm-rights` 与界面确认框仅记录操作者的声明，不验证身份或授权文件，也不会自动提供法律合规。不得用于冒充真实个人、诈骗、虚假背书、骚扰、政治/金融欺骗或侵犯隐私。公开内容应清晰标明为合成语音，避免造成真人说过某段话的误解。

## 本地也有数据风险

- 角色卡复制原始参考，输出元数据可能包含台词、完整转录、绝对路径、后端结果和指令；worker 请求、结果和日志也可能含敏感信息。
- 保存目录应由你控制，使用最小文件权限、必要备份与适当保留期限。删除时同时检查角色副本、后端 input/output、日志与备份，不要假定删除原文件就删除所有副本。
- 不提交参考、生成音频、模型权重或真实用户配置。忽略规则只是防误提交辅助，不是数据防泄漏系统。
- 不执行不可信模型附带代码、worker、配置或脚本。不加载来源不明的角色目录。哈希只检测意外修改，不证明资产真实或有授权。

## 本机默认，不是托管服务

界面建议绑定 `127.0.0.1`。公网监听、分享链接、反向代理或多人使用需要单独的鉴权、TLS、配额、审计与文件隔离设计，本 Alpha 不提供这些保证。ComfyUI 等后端也应限制为可信网络；不要把远程 URL 或共享目录视为可信边界。

一次只运行一个重模型；GPU OOM 不应靠静默降低参数、换模型或下载资产掩盖。适配器失败时应保留可理解的诊断，不宣称生成成功。

## 演示发布规则

当前只允许把选定本地合成参考用于私有验收，不代表允许公开发布。公开参考、结果、演示录屏或测试包前，必须单独核实授权范围、第三方归属及隐私信息。未取得公开许可时，只公布无音频的测试方法/结果摘要；不要把私有音频拷贝进项目。

安全问题请按[安全报告流程](<../SECURITY.md>)处理，不在公开 issue 中附原声、授权证件、密钥或可被滥用的个人信息。
