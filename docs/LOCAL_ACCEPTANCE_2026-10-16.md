# 本机验收 · 2026-10-16

## 克隆入口与内存优化

参考克隆页新增并默认使用已配置的 Qwen Base 0.6B，修复该入口缺少 Qwen 选择及使用 IndexTTS 参数的问题。原有日志没有新的 Qwen 克隆 OOM，不能将用户遇到的错误直接断言为内存不足。IndexTTS 执行错误现在直接展示节点异常。

模型调用使用跨线程、跨进程的资源锁，独立模型调用前释放本机闲置 ComfyUI/IndexTTS 缓存；已有排队任务不会被打断。Qwen 内存错误清理后重试一次，长台词最多 100 字符一段并复用参考声音条件。

真实本机克隆验收：项目自生成参考 + 长台词，2 段 / 25.36 秒 / 24 kHz，峰值显存 2,788,283,904 字节；GPU 总占用 1342 MiB → 1340 MiB（结束后）。详细记录：`.local-data/memory-acceptance.json`。这验证生成链路与资源释放，不代替人工听感确认。

浏览器验证上传合成参考音频、填写对应转录和新台词，默认 Qwen 后端成功生成 5.12 秒音频，显示下载入口及完成状态，浏览器 error 日志为空。结果：`outputs/studio/4353170c01c54007b602144fc78f8a2c.wav`；截图：`.local-data/studio-clone-memory.png`。未代用户保存新的已审听角色。

最终回归：192 项测试，191 项通过、1 项可选测试跳过，14.922 秒。包括跨进程互斥、释放失败后解锁、ComfyUI 忙碌不被中断、异步缓存释放、Qwen 内存错误重试一次、其它错误不重试、克隆专用参数与长台词文本完整性。日志：`.local-data/test-results-memory-final.log`。

环境：Windows、Python 3.12.10、RTX 4060 Laptop 8GB，使用已有的 Qwen 隔离环境和本地模型文件。

## 后续修复：生成报错与简化入口

用户反馈生成报错后，服务日志显示两次请求均被未勾选的设计用途确认拦截；原来的统一异常文案又追加模型环境排查建议，造成误导。进阶页现会在用途确认前禁用生成/追加按钮，输入校验错误只显示具体原因。

新增默认首页「简化版 · 一句话生成」，仅一个描述输入框，无参数或确认框。直接读取本地模型 generation_config，短试听上限 1024 tokens；自动检测后端 CUDA、选择随机种子并提供中文试听句。设备检测失败会明确报错，不伪装成 CPU 可用；生成失败清空试听输出，不保留上一段声音冒充本次结果。

新增回归后执行 154 项测试：153 项通过、1 项可选外部 AST 测试跳过，9.418 秒。浏览器实测空描述显示具体填写提示；随后只填写“温暖沉稳的成年男声，中低音，略带磁性，吐字清晰，像一位耐心讲故事的旅人。”并点击生成，成功显示约 5 秒音频、下载入口和完成状态。实际模型加载 5.512 秒、推理 10.577 秒，使用 CUDA / FP16，浏览器未记录 error 日志。
