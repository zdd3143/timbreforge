# 公开示例：顾星河，夜航维修师

这是一个完全原创、可公开分发的角色设定示例。它不包含真人姓名、私人资料、参考录音或第三方角色设定。

## 输入到「角色设定 → 声线推演」

```text
角色名：顾星河
年龄与身份：34岁，远洋货运飞船的夜班维修师。
性格：耐心、谨慎，遇到故障时先确认事实再行动。平时不爱长篇解释，但会用简短的话让新手安心。
经历：年轻时曾在一次维修事故中判断失误，从此养成了每次操作前复述步骤的习惯。
说话习惯：句子短，停顿清楚；安慰别人时不说空泛的保证，而是先告诉对方下一步做什么。
声音要求：成年男性，中低音，温和但不轻浮，略有疲惫感，吐字清楚，不要播音腔，不要夸张的英雄感。
使用场景：夜间通讯、故障排查、带新人完成第一次舱外维修。
```

## 预期会得到什么

模型会先给出角色概括、可听见的声线维度、每条建议的设定依据或创作建议，以及待确认的选择。下面是一份**示例结果**，用于帮助新人理解输出形式；实际模型可能换一种合理表达。

### 角色概括

34岁、谨慎耐心的远洋飞船维修师，习惯用清楚的步骤和短句安抚新手。

### 声线提示词（可修改）

```text
34岁成年男性，中低音，温和厚实，带一点连续夜班后的疲惫感，胸腔共鸣自然，语速偏慢但不拖沓，停顿清楚，吐字清晰自然的普通话。解释故障时冷静克制，安慰新人时可靠而具体，避免播音腔、夸张英雄感和过度热情。
```

### 试听台词（可修改）

```text
先别急，红色指示灯代表压力还没稳定。你跟着我的步骤做，我们先关掉二号阀，再确认读数。
```

### 修改提示词的例子

- 想更亲近：把“温和厚实”改成“近距离、柔和，保留清晰声芯”。
- 想更疲惫：把“带一点疲惫感”改成“低能量、略哑，但不能含糊”。
- 想更专业：保留年龄、音高、音色、语速和吐字，补充“术语读得清楚，句尾收得干净”。

修改后点击生成，页面会按当前提示词和台词生成新的试听；输入框里的文字由用户决定，模型不会自动把人物外貌或剧情写进声音提示词。

## 使用边界

这是创作方向，不是声音身份保证。请试听核对台词是否完整、是否有噪声或重复，再决定是否保存为角色参考。示例没有配套音频，也不应被用于冒充真人。
